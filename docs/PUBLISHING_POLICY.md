# 掲載・データ運用方針

ChorusDBJPは合唱作品を探すためのメタデータデータベースです。歌詞、楽譜画像、楽譜PDF、MIDI、録音ファイルを保存・配信しません。

## 掲載する情報

- 曲名
- 作詞者、作曲者、編曲者
- 編成、伴奏、演奏時間、難易度
- 出版社、公式作品ページなどの出典
- 公式または一般公開されている外部ページへのリンク

## 検証状態

- `verified`: 出版社、作曲者、権利者などの一次情報に近い出典で確認済み
- `unverified`: 暫定情報。検索には表示される場合がありますが、正確性を保証しません
- `disputed`: 情報が競合しており、確認中
- `removed`: 曲集誤登録、同名別作品の特定不能、権利申請などにより非公開

## 試聴リンク

ChorusDBJPは試聴音源をホストしません。外部検索または権利関係が確認できる公式ページへ案内します。違法アップロードと判断できる特定コンテンツへの固定リンクは登録しません。

## 訂正と削除

GitHub Issuesの「曲情報の訂正」または「権利・削除申請」から報告できます。出典を確認後、データ修正、リンク削除、掲載停止を行います。

## データ追加ルール

新規登録では、仮連番IDを使用せず、安定した英数字slugを使います。曲集・組曲と単独曲を区別し、同名作品は作者または版情報で識別します。
